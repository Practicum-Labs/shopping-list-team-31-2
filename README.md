# ⚙️ Технологический стек
|Компонент|Технология|Обоснование
|---|---|---|
|🎨 UI|Jetpack Compose|Современный декларативный UI-фреймворк от Google, убирающий большой пласт шаблонного кода по сравнению с XML. Требуется в большинстве от кандидата в вакансиях|
|🗄️ DB|Room|Официальная библиотека от Google, использующая декларативный подход для работы с базой данных SQLite|
|🔌 DI|Dagger 2 - Hilt|Статический DI-фреймворк, позволяющий выявить ошибки настройки на ранней стадии|
|🌐 Network|Retrofit|Библиотека для упрощённого клиент-серверного взаимодействия через REST API|

## ⚙️ Выбранная архитектура: MVI.
Данная архитектура реализует однонаправленный поток данных (Unidirectional Data Flow). При такой архитектуре, state становится единственным источником правды, что делает поведение приложения предсказуемым.

## ⚙️ Тип проекта: Монолитный.
Данный тип проекта подходит для такого небольшого приложения. Он обеспечивает простоту разработки и отладки. Архитектура, при необходимости, может быть расширена до многомодульной без полной переработке кода.
